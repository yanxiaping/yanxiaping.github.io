# Web 餐厅首页复刻
参考网站：https://flameremenrestaurants.vercel.app/

> 基于 HTML、CSS 和 JavaScript 完成的餐厅网站首页复刻项目。

## 项目简介

本项目为一次 Web 页面复刻实践，参考目标网站的页面视觉设计与布局结构，
使用 HTML、CSS 和 JavaScript 对餐厅网站首页进行重新实现。

项目重点并非简单复制页面内容，而是通过对原页面进行结构拆解，
分析页面布局、视觉层级、图片展示、字体样式、间距以及交互效果，
再根据分析结果独立完成页面的前端实现。

通过本次实践，熟悉了从「页面分析 → 结构设计 → 样式实现 → 细节调整 → 
本地调试 → 在线部署」的完整 Web 页面开发流程。

## 实现内容

### 1. 页面结构设计

根据参考页面的视觉结构，对首页进行模块化拆分，
使用语义化 HTML 构建页面结构，使不同功能区域具有清晰的层次关系。

### 2. 页面视觉还原

通过 CSS 对页面进行样式实现和细节调整，包括：

- Flexbox / Grid 页面布局
- 字体与文字层级
- 元素间距
- 图片尺寸与裁剪
- 背景与装饰效果
- 按钮及导航样式
- 页面整体视觉比例

在实现过程中，根据浏览器实际渲染效果不断调整 CSS，
使页面整体视觉效果尽可能接近参考页面。

### 3. JavaScript 交互

使用 JavaScript 对页面中的交互行为进行实现，
使页面不仅停留在静态视觉复刻，而具有基本的网页交互能力。

### 4. 在线部署

项目最终通过 GitHub Pages 完成部署，
实现网页从本地开发到线上访问的完整流程。
